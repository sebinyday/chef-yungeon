# 이윤건 요리사 포트폴리오 (한글판)

이윤건 요리사의 음식 사진과 요리 철학, 경력 및 수상 이력을 담은 **한국어 중심의 개인 포트폴리오 웹사이트**입니다. GitHub Pages에서 바로 배포할 수 있는 HTML·CSS·JavaScript 기반 정적 사이트로, 별도의 설치나 빌드 작업은 필요하지 않습니다.

## 주요 기능

- PC·태블릿·스마트폰에서 화면 크기에 맞게 표시되는 반응형 홈페이지
- 사용자가 제공한 요리 사진 9장(웹페이지용 WebP 이미지로 최적화)
- 「전체 / 일식 / 덮밥·전골 / 양식」 작품 필터
- 사진을 클릭하면 **큰 이미지와 한국어 상세 설명**을 보여주는 팝업
- 팝업에서 이전·다음 작품 이동, `Esc` 키 또는 배경 클릭으로 닫기
- 학력·주방 경험·수상·자격증 소개, 이메일 문의 링크
- 모바일 전용 메뉴와 키보드 접근성 지원

## GitHub Pages에 올리기

`sebinyday` 계정을 사용하는 경우를 기준으로 설명합니다.

1. GitHub 계정에 로그인한 후 이름이 `chef-yungeon`인 **Public 저장소**를 만듭니다.
2. 이 ZIP을 압축 해제하고, 내부 **모든 파일 및 폴더**를 저장소의 최상위에 올립니다. `index.html`이 최상위에 있어야 합니다. (압축 파일 자체나 상위 폴더 한 겹을 올리는 것이 아닙니다.)
3. 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. 브랜치를 **main / (root)**로 설정하고 **Save**를 누릅니다.
5. 배포가 완료되면 `https://sebinyday.github.io/chef-yungeon/`에서 확인할 수 있습니다. 처음 배포하는 경우 몇 분이 걸릴 수 있습니다.

저장소 소유자의 계정명이 다르면 위 주소의 `sebinyday` 부분도 바뀝니다.

## 작품 추가 및 문구 수정하기

- **작품 이름·설명·카테고리·이메일:** `content.js` 파일을 수정합니다.
- **첫 화면·소개·학력·수상·자격증:** `index.html` 파일을 수정합니다.
- **글자 크기·여백·색상·폰트:** `styles.css` 파일을 수정합니다.
- **갤러리·필터·팝업 기능:** `main.js` 파일에 들어 있습니다. 일반적인 사진·설명 변경에는 수정할 필요가 없습니다.
- **사진 파일:** `assets/images/` 폴더에 있습니다. 새 이미지를 추가할 때 해당 폴더에 저장하고 `content.js`의 `works` 배열에 항목을 추가하세요.

예시 (`content.js` 파일의 작품 항목):

```javascript
{
  id: 'salmon-sashimi',
  title: '연어 사시미 플래터',
  subtitle: '꽃잎처럼 펼쳐낸 연어의 결',
  category: 'japanese',
  categoryLabel: '일식 · 사시미',
  image: 'assets/images/salmon-sashimi.webp',
  alt: '나무 접시에 꽃 모양으로 담긴 연어 사시미',
  description: '실제로 만든 요리의 특징과 조리·플레이팅 의도를 적어주세요.',
  details: ['슬라이스 배열', '입체적 플레이팅']
}
```

- `category`에는 `japanese`(일식), `hot`(덮밥·전골), `western`(양식) 중 하나를 입력합니다. 분류의 한국어 이름은 같은 파일 상단 `filters`에서 수정할 수 있습니다.
- 사진 수가 증가해도 `works` 배열에 같은 형식의 항목을 추가하면 갤러리에 자동 반영됩니다.
- 연락용 이메일은 `content.js`의 `chef.email`을 변경하세요.

## 공개 전에 확인할 사항

1. **음식 이름·설명은 사진을 바탕으로 작성한 초안**입니다. 정확한 요리명, 실제 재료, 조리 방법과 본인의 작업 기여도를 확인하고 수정하세요. 일부 요리는 사진만으로 구체적인 메뉴명을 확정할 수 없어 일반적인 이름을 사용했습니다.
2. 이력서에 기재된 학력, 후라토 식당 주방 경험, 수상 경력, 자격증 7종을 반영했습니다. 공식 학교명, 수상명, 졸업(예정) 여부를 공개 전에 확인하세요.
3. 이력서의 **생년월일, 집 주소, 전화번호, 자격증 번호는 사이트에 넣지 않았습니다.** 반면 취업 연락을 위해 이메일을 공개하도록 설정했으므로 당사자의 동의를 확인해 주세요.
4. 사진에 대한 저작권·촬영자·메뉴 제작자 등의 공개 허락을 확인하세요.

## 파일 구조

```text
index.html             홈페이지 본문·메뉴·소개글
styles.css             화면 디자인과 모바일 레이아웃
content.js             음식 이름/설명/분류/이메일
main.js                갤러리·필터·상세 팝업 작동 코드
.nojekyll              GitHub Pages 설정용 빈 파일
README.md              이 안내문
assets/favicon.svg     사이트 아이콘
assets/images/         음식 사진 9장
```

글꼴은 인터넷 연결 시 Google Fonts의 한글 폰트를 사용하며, 연결되지 않아도 기본 글꼴로 내용을 읽을 수 있습니다.
